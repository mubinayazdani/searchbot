# راهنمای استفاده از ربات تلگرام جستجوی کالا

## معرفی
این ربات تلگرام برای جستجوی کالا در دیتابیس طراحی شده است. کاربران می‌توانند نام یا شماره فنی کالا را در گروه ارسال کنند و اطلاعات مربوطه را دریافت نمایند. همچنین، در صورتی که ربات را استارت نکرده باشند، لینک استارت برای آن‌ها ارسال می‌شود تا نتیجه جستجو را در چت خصوصی دریافت کنند.

## ویژگی‌ها
- دریافت و پردازش فایل اکسل برای بروزرسانی دیتابیس
- جستجوی انعطاف‌پذیر کالاها با قابلیت شناسایی جزئیات ناقص
- ارسال پاسخ مستقیم در گروه یا در چت خصوصی
- نمایش اطلاعات فروشگاه و شماره‌های تماس در نتیجه جستجو

## نصب و اجرا
1. ابتدا مخزن پروژه را کلون کنید:
   ```sh
   git clone https://github.com/your-repository.git
   cd your-repository
   ```
2. کتابخانه‌های مورد نیاز را نصب کنید:
   ```sh
   pip install -r requirements.txt
   ```
3. مقدار `YOUR_BOT_TOKEN` را در فایل `Database.py` جایگزین کنید.
4. ربات را اجرا کنید:
   ```sh
   python Database.py
   ```

## استفاده از ربات
- در گروه: نام یا شماره فنی کالا را ارسال کنید، ربات نتیجه را پاسخ خواهد داد.
- در صورت نیاز به بروزرسانی دیتابیس، فایل اکسل را در پی‌وی ربات ارسال کنید.
- اگر ربات را استارت نکرده‌اید، روی لینکی که دریافت می‌کنید کلیک کنید تا ربات استارت شده و نتیجه جستجو ارسال شود.
